常见问题

什么是资源站？

资源站是提供影视资源数据采集接口的平台，常见接口格式为 JSON 或 XML，可对接苹果CMS、海洋CMS、飞飞CMS等影视系统，用于自动同步电影、电视剧、动漫、综艺等内容。

本站收录哪些类型的资源站？

目前主要收录影视资源站、采集站和播放源，覆盖电影、电视剧、动漫、综艺等方向。所有条目都经过可用性探测，并在资源站详情页展示接口地址与历史状态。

如何添加自己的资源站？

本站数据由定时任务从公开 API 同步，也可以通过管理脚本直接写入数据库。建议先确认接口可访问、返回标准 JSON，并在详情页测试通过后再对外发布。

可用率是如何计算的？

可用率基于最近 30 天的探测记录计算，每次探测记录 HTTP 状态与响应耗时。可用率越高，说明接口越稳定；响应过慢的站点会在监控页标记为警告。

如何选择适合自己的资源站？

建议从可用率、资源量、响应速度和内容分类四个维度综合判断。优先选择可用率 95% 以上、响应稳定且资源更新频率高的站点，并配置 2-3 个备用源降低单点故障风险。
